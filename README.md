# US Midterm Study

This repository contains the public-facing code and methods for a United States midterm-election research project.

The repository includes:

- reusable midterm ingest, validation, modeling, and scoring code under `midterm-model/src/`;
- generic unit tests for the public code under `midterm-model/tests/`;
- selected public method notes under `midterm-model/docs/`;
- the competition-momentum dashboard source and its published display data.

The repository intentionally excludes private research operations, raw evidence captures, run logs, internal contracts, sealed or prospective materials, polling configuration and trial records, local credentials, generated caches, and unreviewed working files. The dashboard describes observed evidence and model inputs; it is not a guarantee or a forecast of election outcomes.

All source data should be obtained from the public sources named in the accompanying documentation. Credentials, when required by a public-source API, must be supplied through the local environment described by the relevant method notes and must never be committed.
