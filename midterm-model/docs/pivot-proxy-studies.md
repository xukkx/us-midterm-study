# 代理量与自建数据：三个新因子的可测路径（2026-08-27）

> 对应用户提出的三个新因子：民粹（左右轮替）、青年性别分化、经济焦虑/对资本主义失去耐心。
> 本文回答两件事：现有封印数据能测到哪一步；封印数据测不到的部分，用在线数据和 LLM 自建数据集时，什么可以做、什么不能做。

## 0. 一条红线（先于一切）

**LLM 生成的"受访者"、"合成民意"、"模拟选民"不得进入任何账本、任何产物、任何答卷。**
理由不是技术上做不到，而是它不是证据：LLM 对"青年男性怎么想"的输出，是它训练语料里叙事的回声，测的是叙事，不是选民。把它当数据，等于把我们想验证的假设当成结论喂回去。

LLM 在本纲领里只允许两种角色：
1. **对真实文本的编码器**（annotator）：给候选人演讲、新闻、公开帖子打"民粹 / 反建制 / 经济焦虑"标签。必须附**人工标注金标集**（≥200 条）报告一致率，编码器版本与提示词冻结入产物，编码结果只作为"测量仪器读数"进入账本，仪器误差随行。
2. **仪器设计的沙盘**：用合成回答测试问卷措辞、桶定义、分解代码是否跑通。沙盘产物标 `synthetic=true`，永不与真实账本混存。

## 2. 在线代理源：分三层，按"免费·有许可·可点时锚定"排序

### 第一层：免费、许可明确、可锚定 → LH-125 侦察
- **FEC 个人捐款批量数据**（公有领域）：小额捐款人数与集中度——"反建制动员"的行为代理；按候选人可与民粹编码对接。已知偏差：捐款人≠选民，ActBlue/WinRed 结构差异。
- **Wikimedia Pageviews API**（CC0）：populism / socialism / Marxism / New Deal / tariff / inflation 等条目日浏览量——公众注意力代理。已知偏差：注意力≠态度，事件驱动尖峰。
- **GDELT GKG**（免费）：新闻主题频度与情绪——议程代理。已知偏差：媒体议程≠公众信念。

### 第二层：免费但许可/ToS 有条件
- Reddit 公开数据（API 付费/限额；学术访问需申请）——青年男女论坛言论的 LLM 编码对象。
- YouTube Data API（配额限制）——评论文本。
- Google Trends：**无官方 API，pytrends 违反 ToS，不用**；如需，走 Trends 网页人工导出 CSV（用户一步）。

### 第三层：撤销（用户决定，2026-08-27）
用户明确：零预算，不做任何真实调查、广告投放或受访者招募。本纲领只做两类事——(a) 对现有封印数据的**假设性分析**（情景、反事实分解、预注册检验）；(b) 从**免费公开**的在线数据（第一层，及第二层中免费可得的部分）提取洞察。任何涉及真人的数据采集均不立项。

## 3. 设计"假设性分析"的正确方式

可以用现有数据和免费在线数据设计小型探索性检验。原则：
1. **先写可证伪预期，再投放/抓取**（同 LH-111 预注册纪律）。
2. **仪器先校准**：LLM 编码器对金标集的一致率 <0.8 不得使用。
3. **代理只能佐证，不能定判**：注意力/捐款/点击 只能与 CES 序列做同向性检验（相关、领先滞后），不能替代它给出"右移幅度"这类硬结论。
4. **合成永不入账**：见第 0 节。
