这次批评改变了什么，以及研究接下来往哪里走

2026年9月8日。本文取代旧报告中对个人转换、永久性、投票退出和候选人供给机制的强解释。历史计算保留，解释和展示已经更正。

问题不只是样本量不够。有些比较即使增加十倍样本，也无法回答“是不是同一个人改了主意”：每届访问不同的人，组内平均值的变化可能来自原有人的转换，也可能来自谁来投票、谁进入这一组，以及调查和档案匹配方式的变化。接下来的研究应该先把这些过程分开，再考虑增加预测模型。

本次已经完成生态界代码更正、公开复现路径修复、年度投票记录审计，并撤下仪表盘中的众院席位点估计。三波面板已找到官方发布版本，但下载受阻，因此尚未计算同人转移。新的前瞻协议冻结了研究规则；它还不是一份已经填完输入并发布的预测。

一个会改变原结论的发现

过去我们把共和党租房者的投票记录比例，从2012年的60.90%降到2024年的36.63%，写成了这个群体退出选民体的证据。这个解释需要撤回。

重新检查年度原始CSV后，2016年的共和党租房者有4,751人，2024年有5,706人。按人口权重计算，档案匹配率从69.63%降到40.72%；但在已匹配者中，有投票记录的比例从74.35%升到89.96%。原来的记录比例满足“匹配率 × 已匹配者的记录票率”这一恒等式，因此它的下降不能单独解释为真实参与下降。逐年复算表及分母

这也不能反过来证明真实投票率上升。已匹配者是一个受到选择的群体；匹配失败可能包含未登记者，也可能来自地址、身份信息或档案覆盖问题。2016—2020年的Catalist和2022—2024年的TargetSmart还涉及供应商及编码变化。2024年人口权重有效样本量约1,318，并非原始人数5,706。2012年年度原始文件当前缺失，所以它的匹配率仍未知。官方的CES权重与匹配说明也明确区分人口、登记选民与投票者目标。

逐项主张卡

所有复算命令均从仓库根目录执行。这里的“复现”指从随仓库发布的县级输入和聚合充分统计重算表格；不等于已把所有历年原始微数据下载与清洗打包。完整范围见复现说明。

1. 高密度地区的生态界不保证更窄

  • 更正后的问题与人群：在不同密度阈值筛出的县内，特定亚群的共和党两党票份额可能落在哪里。不同阈值代表不同地理目标，不能当作同一个全国估计的精度升级。
  • 测量与来源：MEDSL县级总统结果V20.0、对应ACS五年人口构成；2012、2016、2020、2024共12,452个成功连接的县年记录。以人口构成近似实际选民构成是额外假设，绝非全国无假设界。
  • 命令：python -B -m unittest discover -s midterm-model/tests -p test_ecological_bounds.py；python -B midterm-model/public/reproduce.py --check。
  • 结果与局限：两县反例的整体宽度为11/140，筛到90%密度后为1/9，反而变宽。新函数报告县数、票权重和亚群权重覆盖。2024成功连接票权重覆盖约98.59%，还不是全国全覆盖。区间是条件识别界，不是抽样置信区间；ACS误差尚未传播。
  • 替代解释：高密度县的票份额、地理组成和亚群权重同时变化。高密度县整体右移也不等于县内每个亚群右移。拉美裔人口占比不是劳动者身份。

2. 组内项不能改名为同人说服

  • 更正后的问题与人群：CES各届横截面中，各年龄组的构成和平均两党众院投票边际如何共同变化。
  • 测量与来源：累计CES封存输入的9个相邻届对；旧分解聚合值及哈希见公开输入清单。年龄18—21岁只代理新达到资格的年龄段，不涵盖所有首次投票者，也不测量实际首投经历。
  • 命令：python -B midterm-model/public/reproduce.py --check，读取“对称shift-share分解”。
  • 结果与局限：交互项的一半分别分配给构成项和组内项，算术闭合；改变分配方式不产生因果识别。不能用这张表判定首投者是否决定某场选举。
  • 替代解释：固定人的偏好转换、选择性参与、组内人员更替、调查测量变化，都能改变组内平均值。

3. 党派重新认同是待检验解释

  • 更正后的问题与人群：同一人的党派认同、具体议题态度和投票是否以不同顺序变化。
  • 测量与来源：旧稿比较累计CES中的党派认同与五档意识形态分组；它们是不同分类，不是稳定信念与变化标签的直接观测。后续来源是CES三波面板V2.0。
  • 命令／状态：python -B midterm-model/public/reproduce.py --check仅复现已有横截面表；面板经验转移表尚未生成，详见面板可行性记录。
  • 局限：稳定的五档意识形态不证明具体议题态度不变；目前没有识别同一个人重新贴标签或变化的先后顺序。
  • 替代解释：参与选择、组内替换、粗分组掩盖议题变化，以及同时受其他事件影响。即使取得面板，时间先后也不自动等于因果。

4. 持续性要有明确的后续时间窗

  • 更正后的问题与人群：某种地理或人口组的变化，在下一个可比观察期是否持续。县级结果和个人民意必须分别回答。
  • 测量与来源：旧2018—2024出生组切面及密度县结果；新增协议另行冻结，不改既有forward-2026。
  • 命令：python -B research/validity-release-2026-09-08/verify_protocol.py。
  • 局限：年龄=时期−出生队列，三者不能在无约束条件下分别识别。某出生组已经表现偏共和，不构成未来不可逆的选票底线。一届后续结果也不能证明永久性。
  • 替代解释：全国共同摆动、年龄相关变化、迁移、参与率、不同竞选与选区地图。协议将全国摆动扣除列为选后描述，绝不让其进入选前预测。

5. 投票记录下降不等于固定人群退出

  • 更正后的问题与人群：各年CES中pid7为5—7且自报租房或自住房、有正人口权重的受访者；每年人群不同。
  • 测量与来源：2010—2024累计版8年旧充分统计；另直接读取2016、2018、2020、2022、2024年度CSV及各年投票核验代码本。版本、SHA-256和字段写在annual-turnout-sufficient.json。
  • 命令：公开表用python -B midterm-model/public/reproduce.py --check；持有原始CSV时用python -B midterm-model/public/audit_annual.py --raw-dir 本地年度目录 --output 本地审计.json。
  • 结果与局限：旧分母、全体分母、匹配分母、人口和登记权重分别列示。遗漏状态敏感性不能替代未匹配敏感性。2010、2012、2014匹配信息保持未知；仅匹配者比率不能补成总体真值。
  • 替代解释：档案覆盖、供应商、权重、注册与迁移、组内构成、真实参与变化。原文“退出而非转向”已撤回。

6. 未验证的众院映射不能变成席位头条

  • 更正后的问题与人群：给定同一个全国意向数值，不同系数会使逐区情景相差多少；这不是谁将控制众院的估计。
  • 测量与来源：旧公式PVI + 1.3308 × (E − 0.977)的公共展示快照；比较系数0.5。PVI baseline约为两倍Cook PVI。现有谱系不足以证明旧系数可用于众院；参院拟合不能移作众院验证。
  • 命令：python -B midterm-model/public/reproduce.py --check，读取参数敏感性。
  • 结果与局限：E固定6.2时相差4.3392684个百分点。比较模型失败，不构成现有模型有效的证据。仪表盘不再显示D222—223、净翻转和“Flip possibility”；历史审计在折叠区保留。
  • 替代解释：不同院别、历史时期、中心、目标和训练样本会改变系数。旧筛选集合也不是完整竞争席位清单。

7. 全国意向有预测信息，不是支持变化的原因

  • 更正后的问题与人群：同一时点的全国意向能否提高同院别选举结果预测；另一个问题才是选民为何改变意向。
  • 测量与来源：旧全国generic ballot及残差分析；未来输入必须有同一截止日期和历史可用时间。
  • 命令／状态：本次只验证独立协议，尚无新增历史回测分数。
  • 局限：generic ballot本身测量偏好，不是经济、候选人或议题影响偏好的识别设计。残差也不等于纯候选人效应。
  • 替代解释：共同事件、测量误差、遗漏的地方变化和参选选择。

8. 参选者筹到钱，不能排除资金阻止其他人参选

  • 更正后的问题与人群：已参选并匹配成功的候选人中，背书、公共记录、筹款与表现如何相关。潜在但未参选者不在分母里。
  • 测量与来源：旧候选人汇总和公共报告，归档结果不回写。当前公开包没有完整潜在参选者清单，也不声称从头复现该模型。
  • 命令／状态：本次为解释更正；没有新增资金因果估计或“供给第一瓶颈”的检验。
  • 局限：条件于入场，可能把资金门槛挡在样本之外的人排除掉。筹款还可能响应预期胜算，不能把相关系数当作增加资金的效果。
  • 替代解释：招募、预期胜算、进入成本、背书选择和资金共同影响。下一步应建立潜在参选—宣布—退出的事件记录，而不是继续给已有提名人叠加标签。

接下来的研究顺序

先做同人面板。 将参与、报告的投票选择、党派认同分别建转移表，再比较题干一致的具体议题。拉美裔劳动者必须按实际种族／族裔及劳动变量定义，不能以高拉美裔县或无大学学历代替。先报告这组究竟有多少留存受访者、权重有效人数和流失，再决定能回答多细的问题。

随后解释投票记录的测量变化。 已有审计说明匹配率变化足以改变故事，但尚不知道变化来自谁、为什么发生。下一步需要补齐早年年度文件，检查州别、年龄、迁移相关字段、供应商与权重；不能在看到结果后挑一个最支持原叙事的分母。

预测只保留狭窄比较。 先比较透明的同地理历史基线、同院别全国环境，以及至多一个同截止时点的候选人变量。完整周期才是全国层面的独立观察。数据不能满足时间和地图要求时，该比较停止，不能拿事后数据补齐。独立前瞻协议

这套证据目前仍不能判断拉美裔劳动者是否会决定2026年的国会控制权。要回答这一点，需要把实际人群的参与与选择变化，连接到具体州和选区的胜负边际，并处理共同的全国冲击。总统年县级结果或全国亚群趋势，单独都完成不了这一步。
