# v3 增补（2026-08-22，构成×说服分解 · LH-109）——首投族假说定判

- **强形式否定**："首投族决定近年选举结果"不成立。九个届对（2006→2024）shift-share 分解（ΔM = Σ Δs·m₀ 构成 + Σ s₀·Δm 说服 + 交互，恒等闭合 1e-9），**说服效应（组内摆动）在全部九对中主导**；首投段（18-21 岁首次届龄）构成贡献典型 <0.5pp，峰值仅 1.5pp（2008→2010）。
- **小分母警示**：2022→2024 首投贡献占比"61%"是 ΔM 仅 0.8pp 的比值伪影，不构成主导证据（LH-LESSON-289）。
- **弱形式成立**：首投族作为右移信号真实——首投边际 2024 = −0.219（D+21.9），较 2018–2022 的 −0.32~−0.36 右移 10–14pp，与 v2 队列切面（2000 后队列入场即 .34-.40）互证。
- **合流结论**：选举由组内摆动（环境/全国情绪通道）决定——与问一"环境直通 c≈1.33 为最强单一因子"闭环一致。首投族是**温度计**（反映时期冲击的敏感人群），不是**恒温器**（不决定结果）。
